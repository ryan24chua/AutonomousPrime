# Hackathon archive

Material from the Autonomous SG 2026 hackathon, kept for the record. It is not the current design.

- `pitch.pptx`: the 3-minute pitch deck.
- `Autonomous SG 2026_Airbus Track.pdf`, `Autonomous SG 2026_NUS Hackers.pdf`: the event and track briefs.
- `atc-agent-spec/`: the greenfield ATC agent specs (contract, rule registry, private state).
- `atc-agent-docs/`: the early consensus-log proposal.
- `mvp-spec.md`: the hackathon `CLAUDE.md` (team template and agreed MVP spec); code comments cite its sections.
- `challenge-2-brief.md`: the Airbus brief and judging rubric, transcribed.
- `challenge-2-framing.md`: the team's design framing and key citations from its literature review.
- `agent-alignment.md`: the proposed agent agreement from the build day.
